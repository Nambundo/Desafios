# Trilha de Visão Computacional

Este repositório reúne as soluções desenvolvidas durante a **Trilha de Visão Computacional**, disponibilizada pela **NEx Visual**. O objetivo é apresentar implementações práticas dos desafios propostos, aplicando técnicas de Processamento Digital de Imagens e Visão Computacional utilizando Python e OpenCV.

Cada desafio foi desenvolvido seguindo os requisitos da trilha, podendo conter implementações alternativas para fins de estudo e comparação de abordagens.

🔗 **Curso:** https://nexvisual.catalog.instructure.com/courses/viso-computacional

---

## Tecnologias utilizadas

- Python 3
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

---

# Desafios da Trilha

## ✅ Desafio 1 – Background Blur (Efeito de Vídeo Chamada)

Neste desafio, você irá implementar uma solução simples para aplicar o efeito de desfoque no fundo de uma imagem contendo uma pessoa, de forma semelhante ao recurso utilizado em aplicativos de videochamadas.

---

## ✅ Desafio 2 – Reconhecimento Facial

Neste desafio, você irá implementar uma solução simples de reconhecimento facial, semelhante às utilizadas em sistemas de controle de acesso a áreas restritas.

---

## ✅ Desafio 3 – Rastreamento de Objetos

Neste desafio, você irá implementar uma solução simples para rastreamento de objetos em imagens ou vídeos

---

## 🚧 Desafio 4 – Reconhecimento de Poses

 Neste desafio, você irá implementar uma solução simples de reconhecimento de poses, técnica amplamente utilizada em aplicações como análises esportivas.

# Como executar

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/trilha-visao-computacional.git
```

2. Acesse a pasta do projeto:

```bash
cd trilha-visao-computacional
```

3. Instale as dependências:

```bash
pip install opencv-python numpy matplotlib
```

4. Abra o notebook correspondente ao desafio desejado utilizando **Jupyter Notebook** ou **Google Colab**.

5. Execute todas as células em sequência.
